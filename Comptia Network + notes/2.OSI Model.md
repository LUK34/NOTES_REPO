### OSI Model Layers (Top → Bottom)

- **Application** – What the user sees (web browser, email, etc.)
- Present in software

- **Presentation** – Translates, encrypts, compresses data.
- Present in software

- **Session** – Manages connections (start/stop sessions).
- Present in software

- **Transport** – Reliable delivery (TCP/UDP).
- firewall

- **Network** – Routing, IP addresses.
- router

- **Data Link** – MAC addresses, switches, frames.
- switch

- **Physical** – Cables, signals, bits.
- cables

- Easy Acronyms to Remember
- From Layer 7 (Application) → Layer 1 (Physical)
